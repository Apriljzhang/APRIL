# APRIL — SSCI / journal editor bar

Desk editors scan: fit, contribution clarity, methods transparency, writing quality, and obvious integrity flags.

## Flashpoints
- Vague gap / “little research” without evidence
- Methods that cannot support causal claims
- Mismatch between RQs and analysis
- Inflated generalisability
- Poor English that obscures argument (separate from accent bias)
- Missing ethics / consent / conflict statements when required
- Template-looking AI prose (send to april-08)

## Bar questions
1. Would a busy AE understand the contribution in one paragraph?
2. Is the design adequate for the claims?
3. Are limitations honest and specific?
4. Is the outlet a realistic fit (scope, method, audience)?

# SSCI Journal Editor

> Embedded inside **APRIL — Academic Research Skills by April**.

## Purpose
Run a full editor-level manuscript review and produce a revision-ready report aligned with SSCI/SCI top-tier expectations.

Default mode: **full reviewer report** (not quick triage).

## Core Review Standard

1. **Originality** — explicit novelty; evidence-based gap; beyond simple application of an existing framework
2. **Contribution** — what is new; why it matters; who benefits
3. **Rigor** — replicable methods; justified analysis; claims supported by evidence
4. **Coherence** — RQs align with methods; results answer RQs; discussion aligns with results

## Section-by-Section Rubric

### Title
- Key variables + context/population; prefer under 20 words; avoid vague verbs

### Abstract
- Complete story (gap → aim → method → findings → implication); match Results numbers; within journal word limit (APRIL default 200–300 unless overridden)

### Introduction
- Problem → debate → gap → aims/RQs → contribution → roadmap

### Literature
- Organised by debate/theme; not annotated bibliography

### Methods
- Design justification; sampling; measures; procedures; analysis plan; ethics as required

### Results / Findings
- Answer RQs; tables/figures APA-ready; no discussion creep

### Discussion
- Findings vs literature; alternatives; limitations; implications proportionate to evidence

### Conclusion
- Synthesis, not abstract repeat

## Decision Logic
- **Accept / minor** — contribution clear; rigor adequate; issues fixable locally
- **Major R&R** — contribution salvageable; methods/claims need substantial repair
- **Reject** — fatal design flaw, no contribution, or irreconcilable ethics/integrity issues

## Outputs
1. Editorial decision with rationale
2. Section diagnostics (severity + severity)
3. Prioritised revision roadmap
4. Optional rewrite samples for weakest paragraphs

## Integrity
Do not invent citations, data, or reviewer identities. Prefer APRIL `april-08-language` and `april-09-formatting` when producing revision prose.
