# APRIL revision roadmap format

Use after multi-persona review. Compatible with `april-11-revision`.

## Item schema
| Field | Content |
|---|---|
| id | R-01, R-02, … |
| priority | P0 (blocking) / P1 (important) / P2 (polish) |
| persona | methodologist / literature / contribution / clarity / ethics / editor |
| location | section or claim |
| issue | one concrete problem |
| ask | what must change |
| acceptance | how we know it is fixed |

## Rules
- One issue per row (split compound weaknesses).
- Do not rewrite prose here — only specify the ask.
- Cap at ~15 items; merge trivial P2s.
