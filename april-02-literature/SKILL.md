# april-02-literature

APRIL — Academic Research Skills by April.

## Goal
Build a credible evidence base: find, triage, synthesise, and cite honestly.

## Workflow
1. Define search scope (databases, years, inclusion/exclusion).
2. Search and triage; keep a living matrix (claim → source → quality).
3. Synthesise by debate/theme, not paper-by-paper dumping.
4. Flag unverified or missing citations; never invent DOIs/pages.
5. Hand off to methodology or drafting stages with the matrix.

## Outputs
Search log; inclusion decisions; synthesis matrix; citation risk list.
