# april-05-discussion

APRIL — Academic Research Skills by April.

## Workflow
1. Restate key findings (no new analyses).
2. For each finding: link to literature → explanation → boundary conditions.
3. Alternative explanations and specific limitations.
4. Proportionate implications.
5. Style via `april-08-language`. Never invent citations.
