# APRIL — Academic Paper Research & Inquiry Lab

**APRIL** (**A**cademic **P**aper **R**esearch & **I**nquiry **L**ab) is a staged skill suite for journal-style academic manuscripts. All stage guidance is **APRIL-native**.

## What it is for

- Academic journal articles and manuscript drafting
- Problem / purpose / RQ development
- Method-specific analysis and findings writing
- British English academic style (Manchester-inspired phrase moves + humanizer)
- APA formatting and **APA Style JARS** reporting checks
- Discussion section rhetorical moves (APA Discussion Phrases–inspired)
- Multi-persona review and revision / response letters

## Default manuscript contract

| Setting | Default |
|---|---|
| Article length | 6000–8000 words |
| Abstract | 200–300 words |
| Font / spacing | Times New Roman 12pt, double-spaced |
| References | APA |
| Table/figure captions | APA two-line style |
| Language | British English (`april-08-language`) |
| Reporting | APA Style JARS (`references/jars/`) by study type + REC |
