# april-04-analysis

## Goal
Execute (or tightly plan) analysis and draft Findings/Results. Load **one** method card.

## Routing
1. Read `references/method-index.md`.
2. Open exactly one file under `methods/`.
3. Follow that card end-to-end: assumptions → software → diagnostics → tables/figures → findings prose.
4. For reflexive TA, also use `references/rta/` (APRIL RTA pack).
5. Pass findings to `april-05-discussion`; style later with `april-08-language`.

## Rules
- Do not stack unrelated methods in one pass.
- Do not invent results.
- Match numbers in prose to tables exactly.

## JARS (Results / Findings)
Report to `../references/jars/` for the active design:

- **Quant:** effect sizes/CIs and primary vs secondary vs exploratory reporting as the baseline, plus any active module-specific requirements from `jars-quant.md`:
  - participant flow, fidelity, and adverse events for experiments
  - attrition and wave structure for longitudinal work
  - raw-case sequences for N-of-1
  - fit, estimation, respecification, and parameter reporting for SEM
  - priors, posterior summaries, convergence, and model-fit checks for Bayesian work
  - synthesis outputs and bias assessment for quantitative meta-analysis
- **Qual:** themes or categories with evidentiary excerpts, analytic transparency, and methodological integrity.
- **Mixed:** explicit integration products such as joint displays, merged summaries, connected inferences, transformed data products, or meta-inferences.
- **REC:** apply `jars-rec.md` when race, ethnicity, or culture enters sampling, coding, modeling, interpretation, subgroup reporting, or discussion of effects.
