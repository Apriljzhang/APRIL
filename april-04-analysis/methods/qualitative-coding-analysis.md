# APRIL - Qualitative coding and pattern analysis

## When
Use for systematic coding, categorising, matrices, comparisons, and pattern development when the study is not specifically reflexive thematic analysis, grounded theory, IPA, discourse analysis, or another named methodology.

## Steps
1. Define the qualitative question, methodological orientation, epistemology, unit of coding, data corpus, and intended analytic product.
2. Select first-cycle coding approaches that fit the data and question, then explain whether coding is inductive, deductive, abductive, semantic, latent, descriptive, process-oriented, values-oriented, or another explicit combination.
3. Treat coding as researcher-generated interpretation, not neutral extraction. Keep analytic memos that distinguish data, codes, categories, themes, concepts, and emerging claims.
4. Recode recursively. Record code revisions, mergers, splits, negative cases, disagreements, and consequential decisions in an audit trail.
5. Use second-cycle coding, matrices, pattern comparison, case summaries, or visual displays to develop higher-order relationships without forcing premature coherence.
6. Test candidate patterns against the full corpus, exceptions, within-case context, cross-case variation, and plausible rival interpretations.
7. Use software for retrieval, organisation, linking, and transparency; do not describe NVivo or another package as the analytic method.
8. Report researcher role, coding process, codebook use if any, memoing, pattern development, evidentiary excerpts, contradictions, and limits of transferability.

## Stimulated recall material

When the corpus includes stimulated recall interviews, first read `../../april-03-methodology/references/stimulated-recall-interviews.md`. Align original-event timestamps, cue/stop identifiers and interview turns; distinguish observation, participant report and researcher interpretation, and retain the status of event-time recall, hindsight, uncertain/mixed accounts and non-recall. Preserve disagreements across sources. Define coding units and report coded occurrences and distinct participants with their denominators and nesting. Select quality procedures consistent with the stated analytical approach; do not infer population prevalence or a cognitive process directly from mention counts.

## Boundary check
- If using Braun and Clarke's reflexive TA, switch to `qualitative-rta.md` and its full guide.
- If using a reliability/codebook team model, state how coders were trained, disagreements handled, and codebook stability assessed; do not import those criteria into reflexive TA.
- If the methodology is grounded theory, IPA, conversation analysis, narrative inquiry, or critical discourse analysis, redesign under Stage 03 rather than relabelling generic coding.
