# APRIL — Reflexive thematic analysis

## When
Interviews, focus groups, open-text, documents needing patterned meaning with researcher reflexivity (Braun & Clarke).

## Do this
1. Open the full APRIL RTA guide: `../references/rta/SKILL.md` and its `references/` files (upfront decisions, coding, themes, map, quality checklist, pitfalls).
2. Elicit RQs before coding (non-negotiable).
3. Settle epistemology, coding orientation, analytic level, RQ linkage, data scope.
4. Run six phases recursively; avoid “themes emerged”.
5. Write findings that answer RQs with extracts as evidence.
6. Apply `april-08-language` to prose; APA via `april-09-formatting`.

## Out of scope here
IPA, grounded theory, discourse/conversation/narrative analysis — say so and redesign under april-03 if needed.
