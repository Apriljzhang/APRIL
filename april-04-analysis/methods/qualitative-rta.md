# APRIL — Reflexive thematic analysis

## When
Interviews, focus groups, open-text, documents needing patterned meaning with researcher reflexivity (Braun & Clarke).

## Do this
1. Open the full APRIL RTA guide: `../references/rta/guide.md` and its `references/` files (upfront decisions, coding, themes, map, quality checklist, pitfalls).
2. Elicit RQs before coding (non-negotiable).
3. Settle epistemology, coding orientation, analytic level, RQ linkage, data scope.
4. Run six phases recursively; avoid “themes emerged”.
5. Write findings that answer RQs with extracts as evidence.
6. Apply `april-07-language` to prose; APA via `april-08-formatting`.

## Boundary check
- Reflexive TA treats coding and theme development as situated, recursive interpretation; researcher subjectivity is an analytic resource rather than noise to eliminate.
- Codebook, hybrid deductive-inductive, or reliability-oriented TA can be legitimate, but they use different quality logics. Name the approach and do not silently combine them with reflexive TA.
- Do not present inter-coder agreement as a default quality criterion for reflexive TA.

## Out of scope here
IPA, grounded theory, discourse/conversation/narrative analysis — say so and redesign under april-03 if needed.
