# APRIL — Latent class analysis

## When
Categorical/ordinal indicators (not continuous-profile LPA).

## Steps
1. Confirm measurement level.
2. Fit 1…K; information criteria, BLRT, entropy, bivariate residuals.
3. Interpret item-response probabilities; name classes carefully.
4. Covariates/distals with appropriate 3-step methods.
5. Keep LCA vs LPA wording distinct in Methods.
