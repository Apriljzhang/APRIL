# APRIL — Cross-lagged panel (CLPM / RI-CLPM)

## When
Multi-wave panel; reciprocal lagged effects.

## Steps
1. Prefer RI-CLPM when stable trait variance confounds classic CLPM lagged paths.
2. Justify lags, constraints, covariates.
3. Nested comparisons; standardised lagged paths with CIs.
4. Path diagrams via april-03.
5. Avoid causal overclaim from lagged associations alone.
