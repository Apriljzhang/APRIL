# APRIL — Purpose in the Introduction

Use with `../april-01-ideation/references/purpose-statements.md`. Draws on USC-style introduction structure (inverted triangle; niche; roadmap) and CARS-like moves.

## Introduction spine (APRIL)
1. **Territory** — importance of the topic (world and/or discipline).
2. **Niche** — gap, conflict, or unresolved need (evidenced).
3. **Occupy** — purpose statement; RQs/hypotheses; brief design; contribution; roadmap.

## Where the purpose sits
Usually late in the Introduction (after problem and gap): past or present tense is field-dependent (“The purpose of this study was/is to …”). Follow with design rationale in one or two sentences, then RQs if not already listed.

## Checklist
- [ ] Problem ≠ purpose ≠ RQs (three distinct jobs)
- [ ] Purpose names intent, core constructs/phenomenon, and population/setting
- [ ] Delimitations stated as design choices
- [ ] Roadmap ends the Introduction
- [ ] No dictionary-definition opener; no invented gap
