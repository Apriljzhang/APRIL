# APRIL — APA Style JARS

Use [APA Style JARS](https://apastyle.apa.org/jars) as the transparency/reporting contract alongside APRIL house style (British English, APA citations, etc.).

## Mandatory loading sequence

1. Identify whether the manuscript is quantitative, qualitative, or genuinely mixed methods.
2. Read the applicable checklist file in full. For mixed methods, read `jars-mixed.md`, `jars-qual.md`, and `jars-quant.md`; MMARS adds integration requirements but does not replace strand-specific standards.
3. For quantitative work, begin with JARS–Quant Table 1 and add every design or analysis module that applies. Modules are cumulative, not alternatives to Table 1.
4. Consider `jars-rec.md` for every manuscript and apply the relevant items whenever race, ethnicity, culture, language, nationality, or population generality enters the study.
5. Use only the section-specific items during drafting. During stages 09–11, run the complete applicable checklist across the manuscript.

Do not treat a directory pointer as a completed JARS check. The checklist files contain APRIL's complete, paraphrased operational guidance; the official APA PDFs remain authoritative when exact wording or formal attestation is required.

## Which set?
| Study type | Pack |
|---|---|
| Numerical / statistical reporting | `jars-quant.md` (always start with general Table-1 items) |
| Natural-language / qualitative primary | `jars-qual.md` |
| Qual + quant integrated | `jars-mixed.md` (plus Qual + Quant) |
| **All** manuscripts | Consider `jars-rec.md`; apply relevant race, ethnicity, and culture items |

## Coverage bundled in APRIL

- **JARS–Quant:** Table 1; Table 2 and Modules A–C; Tables 3–9, including the Table 6 replication standard.
- **JARS–Qual:** primary qualitative research (Table 1) and qualitative meta-analysis/QMARS (Table 2).
- **JARS–Mixed/MMARS:** mixed-methods reporting and integration requirements, used with both strand checklists.
- **JARS–REC:** race, ethnicity, and culture guidance across framing, literature, method, analysis, discussion, and citation practice.

These are reporting standards, not a universal substitute for design-specific guidance such as CONSORT, PRISMA, STROBE, COREQ, or discipline- and journal-specific requirements.

## Stage map
| APRIL stage | JARS focus |
|---|---|
| 01 ideation | Aims; primary/secondary/exploratory; REC framing of questions |
| 02 literature | Relevant scholarship; REC citation praxis / transferability critique |
| 03 methodology | Method overview, participants, sampling, measures, diagnostics plan, integrity |
| 04 analysis | Results/Findings reporting (stats or themes); REC analytic choices |
| 05 discussion | Support/nonsupport, interpretation, generality/transferability, implications |
| 06 framing | Introduction problem / review / aims (Quant+Qual) |
| 07 abstract | Abstract elements for Quant / Qual / Mixed + REC |
| 08 language | Bias-free / precise REC terminology (with house style) |
| 09 formatting | Pre-submission JARS gate + title/author-note items |
| 10 review | Score manuscript against applicable JARS pack |
| 11 revision | Close JARS gaps; response letter may cite JARS items |

## Integrity
Do not invent compliance. Mark each item **met**, **not met**, **not applicable**, or **unclear**, with a manuscript location or required repair. Do not write empty boilerplate for inapplicable items.
