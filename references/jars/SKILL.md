# APRIL — APA Style JARS

Use [APA Style JARS](https://apastyle.apa.org/jars) as the transparency/reporting contract alongside APRIL house style (British English, APA citations, etc.).

## Which set?
| Study type | Pack |
|---|---|
| Numerical / statistical reporting | `jars-quant.md` (always start with general Table-1 items) |
| Natural-language / qualitative primary | `jars-qual.md` |
| Qual + quant integrated | `jars-mixed.md` (plus Qual + Quant) |
| **All** manuscripts | `jars-rec.md` (race, ethnicity, culture) |

Design modules (experiment, observational, longitudinal, SEM, Bayesian, clinical trials, etc.) live on the APA site; APRIL encodes the **general** Quant/Qual/Mixed/REC items and points method cards to specialised modules where relevant.

## Stage map
| APRIL stage | JARS focus |
|---|---|
| 01 ideation | Aims; primary/secondary/exploratory; REC framing of questions |
| 02 literature | Relevant scholarship; REC citation praxis / transferability critique |
| 03 methodology | Method overview, participants, sampling, measures, diagnostics plan, integrity |
| 04 analysis | Results/Findings reporting (stats or themes); REC analytic choices |
| 05 discussion | Support/nonsupport, interpretation, generality/transferability, implications |
| 06 framing | Introduction problem / review / aims (Quant+Qual) |
| 07 abstract | Abstract elements for Quant / Qual / Mixed + REC |
| 08 language | Bias-free / precise REC terminology (with house style) |
| 09 formatting | Pre-submission JARS gate + title/author-note items |
| 10 review | Score manuscript against applicable JARS pack |
| 11 revision | Close JARS gaps; response letter may cite JARS items |

## Integrity
Do not invent compliance. If an item does not apply, skip it; do not write empty boilerplate.
