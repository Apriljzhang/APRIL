# APRIL — JARS–Mixed (MMARS)

Adapted from the mixed methods reporting table currently present in the vault source PDF `JARS_mixed-table-1.pdf`.

**Always pair this with both** `jars-qual.md` and `jars-quant.md`. MMARS does not replace strand-specific reporting; it adds the integration contract.

## Title / author note / abstract
- Use `mixed methods` explicitly, or clearly indicate that both qualitative and quantitative methods were used.
- Avoid titles that sound only qualitative or only quantitative when the paper depends on integration.
- In the abstract, include:
  - mixed methods design type
  - participants or data sources
  - analytic strategy
  - main results or findings
  - major implications or significance
- If useful, include one keyword for the mixed design type and one for the research problem.
- If multiple approaches to inquiry were combined, describe them in the abstract only when it materially improves intelligibility.

## Introduction

### Problem and rationale
- Meet the relevant JARS–Qual and JARS–Quant expectations.
- Show why the problem requires **both** qualitative and quantitative evidence when that is the logic of the study.
- Explain barriers or gaps in the literature that motivate collecting both forms of data.

### Objectives / aims / goals
- State **three** goal sets:
  - qualitative goals
  - quantitative goals
  - mixed-methods goals
- Order those goals to match the design sequence.
- Define the mixed goal in terms of what integration adds, not as a vague umbrella objective.
- Describe how approaches to inquiry were combined when that helps explain the rationale.

## Method

### Research design overview
- Explain why mixed methods is appropriate for the paper's goals.
- Name and define the mixed methods design type.
- Identify the qualitative approach to inquiry and the quantitative design used within that mixed design.
- If multiple inquiry approaches were combined, describe how and why.
- State the rationale for collecting both kinds of data and the added value of integrating them.

### Participants or other data sources
- Meet both the qualitative and quantitative strand requirements.
- Clearly identify qualitative versus quantitative data sources.
- Describe the relationship between the datasets, especially for embedded or linked designs.
- Order data-source descriptions to match the study sequence.
- Use an implementation matrix when helpful:
  - goals
  - sources
  - timing
  - anticipated outcomes

### Researcher description
- Because mixed methods includes a qualitative strand, describe relevant researcher background and reflexivity.
- Where relevant, note researcher or team experience with both qualitative and quantitative work.

### Recruitment, sampling, and collection
- Describe recruitment and sampling separately for each strand.
- Keep the order aligned with the actual mixed design sequence.
- Describe collection procedures separately unless a single integrated description is clearer and still preserves strand clarity.

### Data analysis
- Devote separate sections to:
  - qualitative analysis
  - quantitative analysis
  - mixed analysis
- In the mixed analysis section, specify how integration occurred:
  - merged
  - connected
  - embedded
  - transformed
  - joint-display based
- Do not leave integration implicit.

### Integrity
- Cover:
  - methodological integrity for the qualitative strand
  - validity and reliability for the quantitative strand
  - mixed-methods legitimacy or validity of integration inferences
- The key question is whether the integration claims are warranted by the way the two strands were related.

## Findings / Results
- Present results in a sequence that matches the mixed methods design.
- If concurrent, maintain a clear narrative audit trail so the reader can track each strand and the integration point.
- Explicitly report integration products:
  - joint displays
  - merged summaries
  - connected inferences
  - transformed data products
  - meta-inferences
- Avoid writing what amounts to two parallel papers glued together.

## Discussion
- Meet the relevant JARS–Qual and JARS–Quant discussion expectations.
- Explain what the integrated findings add beyond either strand alone.
- Reflect the mixed design sequence in the discussion where that helps readers follow the argument.
- Treat integration as a substantive result, not just a design label.
