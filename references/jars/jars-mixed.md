# APRIL — JARS–Mixed (MMARS)

Adapted from Levitt et al. (2018) Mixed Methods Article Reporting Standards. **Also meet** `jars-qual.md` and `jars-quant.md` for the respective strands.

## Title / abstract
- Use “mixed methods” (or qualitative **and** quantitative); avoid titles that sound purely qual or purely quant.
- Abstract: mixed-methods design type; participants/sources; analytic strategy; main results/findings; implications; keywords for design type + problem; approach(es) to inquiry if helpful.

## Introduction / aims
- Barriers that motivate **both** data types when relevant.
- State **three** goal sets — qualitative, quantitative, and mixed — ordered to match the design.
- Describe how approaches to inquiry were combined; define the mixed goal as what integration yields (e.g. explain survey patterns with interviews).

## Method
- Why mixed methods fits the goals; name and define the design type (e.g. convergent, explanatory sequential, exploratory sequential, or linked variants).
- Qualitative approach + quantitative approach within that design; rationale for collecting both and for **integrating**.
- Separate (or clearly ordered) descriptions of samples/sources; relationship between datasets; implementation matrix when helpful (aims × sources × timing × anticipated outcomes).
- Researcher experience with both strands; reflexivity as for Qual.
- Separate recruitment/sampling/collection/analysis sections ordered by design sequence.
- **Mixed analysis:** how results are mixed (merged, connected, etc.).
- Integrity: methodological integrity (qual) + validity/reliability (quant) + mixed-methods legitimacy of integration inferences.

## Findings / Discussion
- Present strands in a sequence that matches procedures (or a clear narrative audit trail if concurrent).
- Explicit integration products (joint displays, meta-inferences), not two parallel papers glued together.
- Discussion should credit what integration adds beyond either strand alone.
