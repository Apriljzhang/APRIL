# APRIL — PRISMA / systematic review notes

Use when the design is a systematic or scoping review (not every literature stage).

## Minimum record
- Protocol note (aims, eligibility, databases, dates)
- Search strings per database
- Screening flow counts → PRISMA diagram (april-03 diagrams)
- Data extraction fields
- Risk-of-bias / quality appraisal tool named
- Synthesis plan (narrative, meta-analysis, etc.)

## Diagram
Identification → screening → eligibility → included, with n at each box and exclusion reasons.
