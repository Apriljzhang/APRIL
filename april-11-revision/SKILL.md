# april-11-revision

APRIL — Academic Research Skills by April.

## Workflow
1. Number each reviewer comment.
2. For each: stance (agree/clarify/disagree-with-evidence), evidence, manuscript location of change.
3. Respectful, specific tone.
4. Re-run language/formatting stages as needed.
5. Response letter table: Comment → Response → Location.
